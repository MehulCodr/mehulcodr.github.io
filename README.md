# Mehul Gupta · Portfolio

A static portfolio built with HTML and CSS. Edit the content in `index.html` and the layout and colors in `styles.css`.

## Preview locally

From this directory, run `python3 -m http.server 8000 --bind 127.0.0.1`, then open [localhost:8000](http://localhost:8000).

## Publish on GitHub Pages

The [portfolio repository](https://github.com/MehulCodr/mehulcodr.github.io) publishes to [mehulcodr.github.io](https://mehulcodr.github.io/) from the root of its `main` branch. Changes pushed to `main` trigger a Pages deployment. The `.nojekyll` file tells GitHub Pages to serve the static files directly.

[GitHub Pages publishing instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
